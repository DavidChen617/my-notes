# C 語言指標(Pointers)完整指南

## 什麼是指標?

指標的本質非常簡單:**指標就是一個數值,而這個數值剛好是另一個記憶體位址**。

### 記憶體的運作方式

記憶體有兩個核心特性:
- **位址(Address)**: 記憶體的位置
- **數值(Value)**: 儲存在該位置的資料

舉例:
```c
int x = 4;  // 假設儲存在位址 0x1000,數值為 4
```

當我們在另一個位址(例如 0x1004)儲存數值 0x1000 時,就創建了一個指標!

## 指標的語法解析

### 1. 創建變數與指標

```c
int x = 4;           // 創建整數變數
int *px = &x;        // 創建指向 x 的指標
```

**語法拆解:**

#### 第一行: `int x = 4;`
- `int`: 型別(4 bytes)
- `x`: 變數名稱
- `=`: "被設定為"
- `4`: 數值

**解讀**: 整數變數 x 被設定為 4

#### 第二行: `int *px = &x;`
- `int *`: 指向整數的指標型別
- `px`: 指標變數名稱(p 代表 pointer)
- `=`: "被設定為"
- `&x`: x 的位址

**解讀**: 整數指標 px 被設定為 x 的位址

### 2. 重要符號說明

| 符號  | 在型別旁      | 單獨使用  | 意義                                 |
| --- | --------- | ----- | ---------------------------------- |
| `*` | `int *px` | `*px` | 在型別旁=指標型別<br>單獨使用=解參考(dereference) |
| `&` | -         | `&x`  | 取得位址                               |
|     |           |       |                                    |

### 3. 解參考(Dereference)

```c
int y = *px;  // 取得 px 指向的數值
```

- `*px` 意思是"前往 px 指向的位址並取得該數值"
- 因為 px 指向 x,所以 `*px` 會得到 x 的數值
- 最終 y = 4

**解讀**: 整數 y 被設定為 px 指向的東西

## 為什麼需要使用指標?

### 理由 1: 按引用傳遞(Pass by Reference)

在 C 語言中,為了讓程式碼可讀且可擴展,我們會將功能拆分成不同函式。但變數的作用域(scope)可能不在函式內。

```c
struct Person {
    int age;
};

void update_age(struct Person *p, int new_age) {
    p->age = new_age;  // 透過指標修改結構體
}
```

**好處:**
- 保持程式碼乾淨易懂
- 避免複製資料,節省記憶體空間
- 可以直接修改原始資料

### 理由 2: 動態記憶體配置

C 語言中有兩種記憶體配置方式:

#### 靜態配置(Static Allocation)
- 儲存在堆疊(Stack)上
- 大小在編譯時期就已知
- 總是在函式作用域內

```c
int x = 4;  // 靜態配置
```

#### 動態配置(Dynamic Allocation)
- 從堆積(Heap)取得記憶體
- 透過 `malloc` 等函式配置
- 大小可在執行時期決定
- **必須使用指標**

```c
char *str = malloc(100);  // 動態配置 100 bytes
// 這 100 bytes 可能來自使用者輸入或其他來源
```

## 關鍵概念總結

### 口語化理解 C 語法

| C 語法 | 口語化表達 |
|--------|-----------|
| `int x = 4;` | 整數 x 被設定為 4 |
| `int *px = &x;` | 整數指標 px 被設定為 x 的位址 |
| `int y = *px;` | 整數 y 被設定為 px 指向的東西 |

### 記憶訣竅

1. **`&` = "取得位址"** (address of)
2. **`*` 在型別旁 = "指標型別"** (pointer to)
3. **`*` 單獨使用 = "指向的東西"** (the thing pointed to by)

## 實用範例

```c
// 基本指標操作
int x = 4;              // x 的值是 4,假設位址是 0x1000
int *px = &x;           // px 儲存 x 的位址(0x1000)
int y = *px;            // y 取得 px 指向的值,所以 y = 4

// 修改指標指向的值
*px = 10;               // 現在 x 的值變成 10

// 動態記憶體配置
int *arr = malloc(10 * sizeof(int));  // 配置 10 個整數的陣列
arr[0] = 5;             // 使用陣列
free(arr);              // 記得釋放記憶體!
```
